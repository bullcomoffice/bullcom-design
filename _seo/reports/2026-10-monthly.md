### サービスページ2つの原因調査

| 確認したこと | 結果 |
|---|---|
| HTTP 応答・noindex・X-Robots-Tag | 200、どちらも無し（登録済みの `/services/branding` と同じ） |
| canonical・サイトマップの表記 | 自分自身・末尾スラッシュ無しで一致 |
| 内部リンク | トップ・`/services`・兄弟ページの HTML に直接リンクあり（JavaScript 不要）。**登録済みの branding・contents と全く同じ** |
| 本文量 | web 1,571字・graphic 1,359字。登録済みの branding 1,144字・contents 1,196字より多い |
| ライブテスト（10/24） | 「URL は Google に登録できます」。クロール可・取得成功・インデックス可 |
| 申請の記録 | web は 9/27・10/3・10/12・10/18、graphic は 9/27・10/12・10/18 に受理 |

**結論**: ページ側に直すべき欠陥は見つからない。Google が 9/7 に `/services` を巡回したときに branding・contents だけを拾い、
web・graphic を巡回の対象に入れていない状態と考えられる。申請を繰り返しても動かないので、**Google に「重要なページ」と伝わる経路を増やす**のが打ち手。
とくに、登録済みで検索表示もある料金ページ `/price` から、サービスページへのリンクが1本もない。
